BLACK HOLE SIMULATION GUIDE

1.  Schwarzschild Radius Rs = (2 * G * M) / c^2

2.  Zones

-   Event Horizon: r <= Rs → object absorbed
-   Photon Sphere: r ≈ 1.5 Rs
-   Singularity: center point

3.  Gravity F = G M m / r^2 a = G M / r^2

4.  Update Loop velocity += acceleration * dt position += velocity * dt

5.  Lensing alpha = 4GM / (c^2 r)

6.  Accretion Disk v = sqrt(G * M / r)

7.  Time Dilation t’ = t * sqrt(1 - Rs / r)

8.  Basic Code Structure (pseudo)

class BlackHole: mass position Rs

class Particle: position velocity

loop: for particle: compute distance r if r <= Rs: destroy compute
acceleration update velocity update position
